# Traders Journal

A privacy-first Windows trading journal and analytics workstation, with live MetaTrader 5 sync built in.

## Download

Get the latest version from [Releases](../../releases/latest):

- **Traders-Journal-Setup-x.y.z.exe**: installer (recommended). The installed app updates itself automatically.
- **Traders-Journal-Portable-x.y.z.exe**: runs without installing.

Windows 10 or later. Your trading data stays on your computer.

This repository holds the app downloads only.
